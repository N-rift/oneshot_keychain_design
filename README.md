# ONESHOT Keychain Design

## Overview

This project presents a custom keychain based on the ONESHOT logo.

The logo was recreated as a 3D model, modified with a 4 mm hole for key attachment, and extruded to a thickness of 2 mm. The final model was exported as an STL file for 3D printing.

## Design Specifications

| Feature | Value |
|----------|----------|
| Hole Diameter | 4 mm |
| Thickness | 2 mm |
| File Format | STL |
| Software | Fusion 360 |

## Files Included

- `oneshot_keychain.stl`
- `oneshot_keychain.png`

## Design Process

1. Selected the ONESHOT logo.
2. Recreated the design in Fusion 360.
3. Added a 4 mm circular hole.
4. Extruded the model to 2 mm thickness.
5. Exported the final model as an STL file.
